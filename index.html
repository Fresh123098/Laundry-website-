🖨️ Printer Setup Guide

  1. Connect your printer to your device (USB/Bluetooth).
  2. For thermal 80mm printers, in Chrome go to Print → More Settings → Paper size → Custom → Width: 80mm, Height: 297mm.
  3. For A4 printers, keep default A4 size.
  4. Enable "Background Graphics" in print options to include the logo.
